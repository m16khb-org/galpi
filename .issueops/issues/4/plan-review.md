# 계획 검토 기록

## 1차: 수정 요청

- 1차 계획 검토(anthropic/claude-opus-5-5, high): 수정 요청 4건. 로그아웃 게이트가 null 키 이름까지 세어 통과할 수 없는 문제, 테스트용 비밀 저장소가 쓰기 횟수를 세지 않아 쓰기 횟수 테스트가 항상 통과하는 문제, 긴 회의 맵 단계가 한도 초과 뒤에도 대기 중인 요청을 계속 보내는 문제, 모델 목록 조회가 만료된 access token을 갱신하지 않아 재시작 다음 날 목록이 비는 문제를 지적했습니다.

## 2차: 수정 요청

- 2차 계획 검토(delta, anthropic/claude-opus-5-5, high): 1차 지적 중 로그아웃 게이트, 쓰기 카운터, 모델 목록 갱신은 해소됐습니다. 맵 단계 취소만으로는 이미 시작된 청크 요청을 막지 못해 요청 수 상한 게이트가 흔들리는 문제와, 쓰기 카운터 게이트가 동작이 아니라 rustfmt 줄바꿈 서식을 판정하는 문제 2건을 지적했습니다.

## 3차: 통과

- 3차 계획 검토(delta, anthropic/claude-opus-5-5, xhigh, 3라운드 상향): 공유 실패 플래그 설계로 맵 단계 요청 수가 작업자 수 3 이하로 보장되고, 수정이 빠지면 반복 테스트가 실패한다는 점을 실제 가짜 서버 시뮬레이션으로 확인했습니다. 쓰기 카운터 게이트는 이름 고정 동작 테스트로 바뀌어 실패할 수 있고, API 키 모드의 성공 경로는 바뀌지 않아 기존 테스트에 영향이 없습니다. 실패 경로의 일시적 진행 표시와 G21 문구의 API 키 모드 오류 코드 표현은 비차단 메모로 구현 세션에 넘깁니다.
