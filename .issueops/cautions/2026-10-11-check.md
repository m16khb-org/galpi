# 게이트 CHECK 인자에 비밀처럼 보이는 문자열을 넣으면 명령 정책이 실행을 거부한다

- Date: 2026-10-11
- Kind: `caution`
- Source: issueops-docs io-21fd3b1e1f06 (galpi#12)
- Summary: '소스에 Google 클라이언트 비밀번호가 없다'를 확인하는 게이트가 CHECK 인자에 비밀번호 접두어와 SECRET이 들어간 표식 문자열을 담자 issueops 명령 정책이 secret_like_argument로 거부해 게이트가 unchecked로 남았다.
- Context: galpi#12 G11. 같은 명령을 셸에서 실행하면 정상 동작해 원인이 보이지 않는다. 출력에 자격 증명처럼 보이는 값이 있어도 EVIDENCE가 가려져 EXPECT가 맞지 않는다.
- Resolution: 검색 패턴은 실행 중에 조립하고(chr(71)+'OCSPX'), 출력 표식은 SOURCE_CLEAN/SOURCE_LEAK처럼 중립 단어를 쓴다. 게이트가 unchecked로 남으면 `issueops gates check --json` 결과의 check_error에서 policy_denied 여부부터 본다. 커밋 전에는 새 파일이 미추적이라 `git grep`에 `--untracked`를 붙여야 하고, 접두어만 찾으면 계획·게이트 문서의 설명 문구에도 걸리므로 실제 값 모양(접두어 뒤 `-`와 20자 이상)을 `-E`로 찾는다.
- Evidence:
  - .issueops/issues/12/gates.md G11
  - issueops gates check --json: check_error 'check denied by policy: secret_like_argument'
